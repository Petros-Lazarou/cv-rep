# cv-rep
Το android app , περιεχει το directory για το Android Studio. Ειναι μια εφαρμογη για την εμφανιση συνταγων μαγειρικης.
Το project_os22up ειναι μια εφαρμογη στη C , οπου υλοποιοιει multi threaded tcp ip server για κλεισιμο δωματιων σε ξενοδοχεια , γενικα λειτουργει με τα ξενοδοχεια που περιεχονται στα αρχεια, σε linux, στο replit workspace δουλευει με τα precompiled αρχεια Server.c Client.c .
Στο aiproject χρησιμοποιω cnn network για κατηγοριοποιηση ενος dataset ειδησεων.
